This was an assignment for Programming I at university. The task was to develop from scratch a command-line application to store a collection of a chosen type, with optional subtypes. This should be written to disk and reloaded from a file upon reopening.
The program should also have functions to manipulate the collection and provide information and data on the objects.
I chose to use bottles for the object type, with flasks as a subtype.\
\
The grade for this assignment was 98%.
